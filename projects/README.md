# projects — every project in the vault

One folder per project, with no intermediate category level. Each project folder follows the standard anatomy (`AGENTS.md`, `.agents/skills/`, `pop/`, content at the root) described in [[AGENTS|AGENTS]], and declares its `type` (`uni-repo` | `multi-repo`) in its own `AGENTS.md` — see [[TYPES|TYPES]].

- Create a project with the `new-project` skill (or import an existing one with `import-project`).
- Every project is registered in the root [[INDEX|INDEX]] (link, status and a description of up to 144 characters); repos with a clone also go into the **Aggregated repositories** list there.
